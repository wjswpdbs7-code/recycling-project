# 하드웨어 배선 가이드 — Pico 2 W 프로토타입

> 작성 2026-07-20. 대상: 서보 SG90 ×2, 초음파 HC-SR04, LCD1602(I2C 백팩), Pico 2 W.
> 테스트 펌웨어: `pico_hw_test/build/pico_hw_test.uf2` (시리얼 명령으로 전 장치 조작)
> Wokwi 시뮬레이션: `pico_hw_test/wokwi/` (diagram.json + main.py)

## 1. 전체 그림

```
                    ┌─ USB ─── 노트북 (시리얼 115200, PuTTY 또는 AI 원격)
              ┌─────┴─────┐
   서보1 ──── │ GP0       │
   서보2 ──── │ GP1       │        LCD1602(I2C 백팩)
              │ GP4  SDA ─│─────── SDA
              │ GP5  SCL ─│─────── SCL
   HC-SR04    │           │
    TRIG ──── │ GP16      │
    ECHO ─1k─►│ GP17      │   (1k/2k 분압: 5V→3.3V)
        └2k─GND           │
              └───────────┘
   전원: Pico·센서·LCD = USB 5V / 서보 = 별도 5V (GND만 공통)
```

## 2. 핀 연결표 (Pico 2 W, USB가 1번 줄 방향)

|---|---|---|---|---|
| 서보1 | 신호(주황) | GP0 | 1 | C1 옆 A1/B1 |
| 서보2 | 신호(주황) | GP1 | 2 | C2 옆 A2/B2 |
| 서보 1·2 | 전원(빨강) | — | — | **별도 5V** (AA×4 홀더 +) |

## 3. 전원 규칙 (사고 방지 2줄 요약)

1. **서보 빨간선은 절대 Pico 핀에서 따오지 않는다** — 별도 5V(AA×4 = 6V 허용, 또는 5V 2A 어댑터). 어기면 서보 움직일 때 보드 리셋.
2. **모든 GND는 파란 레일 하나로 모은다** — Pico GND + 서보 갈색 + 센서 GND + 2k저항 + 배터리(−). GND가 안 만나면 아무것도 동작 안 함.

## 4. 테스트 방법

1. `pico_hw_test.uf2` 굽기 (BOOTSEL 누른 채 USB → 드라이브에 드래그)
2. PuTTY: COM 번호(장치관리자 확인) / 115200 → `>` 프롬프트
3. 명령:

| 명령 | 확인 내용 |
|---|---|
| `all` | 전 장치 자동 점검 (최초 1회 필수) |
| `scan` | LCD I2C 주소 탐지 (0x27/0x3F 정상) |
| `dist` / `watch` | 초음파 1회/연속 — 실패 원인 구분 출력 |
| `s1 90` `s2 45` | 서보 각도 지정 (0~180) |
| `sweep` | 서보 왕복 — 도중 리셋되면 서보 전원 미분리 |
| `lcd HELLO` `lcd2 WORLD` | LCD 1/2줄 표시 (영문·숫자만) |

## 4-1. 검증 완료 사항 (2026-07-20)

- **HC-SR04**: 정상 동작 확인 (3~4cm 근접, 259cm 원거리 모두 안정 측정)
- **LCD1602 I2C**: 백팩 매핑 **MAP A**(P0=RS, P2=EN) 확정.
  글자 깨짐의 원인은 매핑이 아니라 **초기화 타이밍 부족**이었음 →
  나이블당 150us, 초기화 6ms로 여유 확보 후 정상 표시.
  (진단 펌웨어 `lcd_test.uf2`가 MAP A/B를 6초씩 번갈아 표시하여 판별)
- **데모 펌웨어**: `sonar_lcd.uf2` — 초음파 거리를 LCD에 실시간 표시 + 10cm 진입 시 DETECTED

## 5. 문제 해결표

| 증상 | 원인 → 조치 |
|---|---|
| `에코 시작 없음` | 센서 VCC가 3V3에 꽂힘 → VBUS(5V)로 / TRIG 점퍼 확인 |
| `에코 안 끝남(반사 없음)` | 센서가 허공·천장 봄 → 정면 10~20cm에 평평한 물체 |
| `scan`에 아무것도 없음 | LCD SDA/SCL 뒤바뀜 또는 전원 미연결 |
| LCD 켜지는데 글자 안 보임 | 백팩 뒷면 파란 가변저항(콘트라스트) 돌리기 / 3V3→VBUS 승격 |
| `sweep` 중 재부팅 | 서보 전원 분리 안 됨 → 별도 5V + GND 공통 |
| 시리얼에 아무 출력 없음 | 케이블이 충전 전용 → 데이터 케이블로 교체 |
