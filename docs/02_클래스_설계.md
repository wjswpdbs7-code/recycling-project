# 모델 학습 클래스 설계 탐구

> 2026-07-17. AI Hub 생활폐기물(71385) 공식 매핑표 + B2 실데이터(317장) + 공식 Validation(12,784장) 실측 기반.
> **진행 상태(2026-07-18 갱신): 최종 목표를 E안(17클래스, 아파트 규정 풀스펙)으로 상향 확정.**
> **Run A(4클래스 기준선) 학습 진행 중 → Run B는 9클래스 대신 17클래스로 진행 (9클래스는 17에서 추론 병합으로 재현 가능하므로 별도 학습 생략).**

## 1. 설계 목표

- 기기 동작: 4개 품목함(투명페트/플라스틱/캔/유리) + 판별불가함(오염·비대상·저신뢰)
- 학습 클래스는 기기 동작과 별개로, **데이터가 가장 잘 배울 수 있는 단위**로 정한다.
- 판별불가는 학습하지 않는다 — confidence 임계값 + 박스 수 + 센서 융합의 후처리 산물.

## 2. 후보 설계

| 설계 | 학습 클래스 | B2 실측 활용률 | 평가 |
|---|---|---|---|
| A. 4클래스 (클린만) | pet/plastic/can/glass | **13/317 (4%)** | 오염·비대상 데이터 폐기. 실내형분류기 데이터 대부분 버림 |
| B. 5클래스 (오염 단일) | 4 + contaminated | (미실측, ~79%) | 오염 클래스의 시각 다양성 큼 → 학습 난도 ↑ |
| C. 8클래스 (품목별 오염) | 4 + {pet,plastic,can,glass}_dirty | **250/317 (79%)** | 데이터 원형(품목×상태)과 일치. 오염 4종 추론 후 병합 |
| **D. 9클래스 (채택)** | 8 + other(비대상) | **317/317 (100%)** | 비닐→플라스틱 오분류를 other가 흡수. 데이터 전량 활용 |

공식 Validation 실내형분류기 전체(12,784장) 실측에서도 동일 경향 재확인: **모드 4 활용률 38% vs 모드 9 100%.**

### E. 17클래스 (2026-07-18 최종 채택) — 아파트 규정 풀스펙

클린 9종(4품목 + paper, paper_pack(우유팩+종이컵), vinyl, styrofoam, battery) + 품목별 오염 8종.
**other 클래스 소멸** — 아파트 분리배출 규정의 전 품목을 커버하므로 "비대상" 개념이 사라짐.

- 채택 근거: ① 9클래스의 상위집합 — 추론 병합으로 9클래스/5칸 동작 재현 가능 ② 데이터 활용 100% 유지
  ③ 기구는 5칸을 유지하더라도 신규 품목은 "안내 메시지"(배출 코칭)로 활용 ④ 아파트형(9~10칸) 확장 시 재학습 불필요
- Validation 실측(12,784장): 활용 100%, 17클래스 전부 존재. 최소 클래스 paper_dirty 202박스
  (Training 환산 ~1.6천 추정) — 학습 가능선이나 소수 클래스 가중치 필요.
- 추론 병합 계층: 17클래스 → (현 기기) 4품목함 + 판별불가함(dirty 8종+신규품목 5종, 품목명 안내 포함)
  → (아파트형) 9칸 + 판별불가함(dirty만).

### D안 채택 근거
1. **데이터 활용률**: B2 기준 4% → 100%. 실내형분류기 파트가 오염 위주 배치를 다수 포함하므로 격차가 실질적.
2. **비대상 방어**: 시연·실사용 중 비닐/종이 투입은 반드시 발생. other 클래스가 없으면
   비닐봉지가 plastic으로, 종이컵이 pet으로 오분류될 위험. other가 있으면 "비대상 → 판별불가함 + 안내"로 처리.
3. **오염 품목별 유지**: 오염은 품목 형태와 결합될 때 시각 일관성이 높음(단일 오염 클래스보다 학습 유리).
   대시보드에 품목별 오염 통계 부가 효과.

## 4. 추론 → 기기 동작 병합 규칙

```
결과 클래스        → 수거함
0 pet_transparent → 투명페트함
1 plastic         → 플라스틱함
2 can             → 캔함        (금속센서 불일치 시 판별불가)
3 glass           → 유리함      (로드셀 무게로 pet↔glass 교차검증)
4~7 *_dirty       → 판별불가함  + "세척 후 배출" 안내
8 other           → 판별불가함  + "이 기기는 용기류 전용" 안내
박스 0개           → 재촬영 1회 → 판별불가
박스 2개 이상      → 리턴(싱귤레이터) 또는 판별불가
max conf < 0.6    → 판별불가
```

## 5. 알려진 리스크와 대응

| 리스크 | 대응 |
|---|---|
| clean↔dirty 라벨 경계 애매(B2 실물 확인) | dirty 판정은 정밀도 우선: dirty 클래스에 한해 conf 임계값 상향(예 0.7). 애매하면 클린 품목으로 |
| can_dirty(1.4만)·glass_dirty(1.1만) 소수 | 클래스 가중치 또는 dirty 4종을 유지하되 성능 미달 시 pet/plastic_dirty만 남기고 can/glass_dirty→other로 병합하는 축소 실험 |
| other 시각 다양성 큼 | other는 "정확히 뭔지"가 아니라 "4품목이 아님"만 맞히면 됨. recall 목표를 낮게(0.8) 잡고 임계값으로 조정 |
| 클래스 불균형(plastic_dirty 30만 vs glass_dirty 1.1만) | 클래스당 상한 다운샘플링(예: 3만) 후 학습 |

## 6. 실험 계획

1. **Run A (기준선)**: 4클래스, 실내형분류기 클린 데이터만 — 클린 4종 mAP 기준값 확보 ← **현재 단계**
2. **Run B (본명)**: 9클래스, 클래스 균형 샘플링 — 판정 기준: 클린 4종 mAP가 Run A 대비 -1%p 이내면 채택
3. 채택안으로 자체 촬영 fine-tuning (실기기 조명 박스, 클래스당 300~500장 — dirty/other 포함 촬영)

평가지표: 클린 4종 mAP50 ≥ 0.95 / dirty 그룹 precision ≥ 0.9 / other recall ≥ 0.8
시스템 지표(센서 융합 후): 정분류 ≥ 95%, 오분류 ≤ 2% (나머지 판별불가 허용)
