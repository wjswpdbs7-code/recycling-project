## 문서 규칙
- 프로젝트 문서는 이 폴더(docs/)에만 작성·보관한다.
- 결정이 바뀌면 과거 문서를 수정하고 버전 주석을 남긴다 (중복 문서 생성 금지).
- **작업 종료 시 3종을 함께 갱신**: 진행일지(요약) + 포트폴리오 기록(상세) + `img/` 이미지 축적.
  이미지 파일명 규칙: `hw_*`(하드웨어) `test_*`(실물 테스트) `perf_*`(성능) `cad_*`(3D) `runA/B*`(학습).
- 데이터·모델·코드 산출물은 문서가 아니므로 각각 `training/`, `models/`, 프로젝트 루트에 둔다.
